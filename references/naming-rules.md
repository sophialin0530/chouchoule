# 卡名命名规则（根据卡背逐张联想）

> 这是本 skill 的差异化能力之一：卡名必须来自**卡背（背面）画面**，不是随便起名或加编号。

## 流程
1. 先用 `scripts/build_site.py` 生成 `cardback_contact_sheet.png`（或直接在 Phase 3 用 Read 逐张看 `backNN`）。
2. **批量看所有卡背**后，再逐张命名——不要一边抽一边临时起名。
3. 一张卡背对应一个卡名；所有名称**去重**。

## 默认规范
- **默认四个汉字**（如「樱桃物语」「花朝初见」），贴合画面气质，不泛泛。
- 风格可配：少女心 / 浪漫 / 可爱 / 搞怪……由 Phase 1 确认。
- 卡名**不要自动附加编号**（如「晚风秘密 · 22」会破坏四字美感）。序号由系统用 `id` 管理，不进名字。

## 例子
- 卡背是樱桃卷蛋糕 → 产出「樱桃物语」，而不是「甜点 05」。
- 卡背是星空剪影 → 产出「星河信笺」。

## 覆盖表（override）
用户后续可给 `旧名 → 新名` 覆盖表，构建时自动替换：
```json
{ "override": { "樱桃物语": "莓好时光" } }
```
写在 `config.json` 里即可。

## 兜底
若暂未命名，脚本用占位名「未命名 NN」（NN 为序号），站点仍可运行；上线前务必替换成真正卡名。
