# 临时链接 → 稳定链接的迁移 prompt

## 背景
`workbuddy_cloudstudio_deploy` 给的是云端沙箱**临时链接**，可能随时失效。
用户想要稳定长期链接时，**新开一个对话框**，把下面这段 prompt 连同信息一起发过去即可。

## 直接复制发的 prompt
```
帮我把这个抽抽乐网站迁移到稳定长期的线上链接。

信息：
- 站点目录（你的电脑上的 dist 绝对路径）：<把 dist 目录绝对路径贴这里>
  或者临时分享链接：<把之前的 shareLink 贴这里>
- 网站名字：<网站名>
- 要求：重新部署成一个能长期打开、可微信分享的链接，并告诉我新的分享链接。
```

## 为什么要在「新对话框」做
- 当前对话可能已很长、上下文杂；新对话框更干净，且能把「迁移」作为独立任务交给一个干净的会话。
- 迁移本质就是**重新跑一次部署**（或换更稳定的托管），不需要旧对话的上下文。

## 可选：如果用户有自己的托管
若用户有 GitHub Pages / 对象存储 / 自己的服务器，可把 prompt 改成「把这个 dist 目录部署到我的 <托管方式>」，由新对话按对应方式迁移。
