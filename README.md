# 🎴 抽抽乐网站生成器（chouchoule-site-generator）

> 粉丝都在抽的女明星「抽抽乐」，你也能拥有一个专属的。
> 其实不仅可以做你自己照片的抽抽乐，也可以做喜欢的梦角、爱豆、博主或者闺蜜的；不止可以放自拍，合照让对象抽或去过的景色让家人朋友抽也可以作为礼物送给她们，新颖又有纪念价值；放自己的照片的话，像个电子相册，和crush调调情也很好玩。
> **卡背专属设计、卡名 AI 起名、十连抽卡、保底 SSR、图鉴收集、抽卡记录全都有。**
> 不用写代码，三轮对话就能做好，直接发微信链接给 TA 抽。

## 它能帮你做什么

- 📸 **合照变卡牌**：上传一组照片，AI 帮你配卡背、起卡名，做成有收藏感的专属抽卡网站。
- 🎨 **专属卡背 + 卡名**：统一风格 / 分组稀有度 / 逐张定制三种卡背方案；卡名默认四字可爱风，也能诗意、萌系、自定义。
- 🎰 **真·抽卡体验**：单抽 / 十连、新卡翻面揭晓、重复卡缩略图、保底机制、SSR 特效、图鉴解锁、抽卡记录，仪式感拉满。
- 🔗 **微信直接打开**：部署成临时链接，手机点开就能抽，也能打包发给别人接着玩。
- 🎟️ **兑换码系统**：自动生成 10 个普通兑换码 + 1 个万分码，积分说涨就涨。

| **通义千问**（阿里） | 同上 |

> 无论用哪个助手，都会先和你确认需求（网站名 / 风格 / 卡背 / 稀有度），再动手做，不会一上来就要图。

## 三步做好（Phase 1 → 2 → 3）

1. **提取需求**：填一份轻量需求单（带默认选项，直接选或自己填）——网站名、照片方向、风格、卡背方案、稀有度分级、命名风格。
2. **套用工作流**：确认卡背设计、AI 起卡名给你核对、自动生成兑换码、跑质量门禁（数量配对 / 去重 / 保底校验）。
3. **搭建并部署**：一键构建成纯前端网站，部署成可微信打开的临时链接，并附「迁移到稳定链接」的提示。

## 目录结构

```
gacha-site-builder/
├── SKILL.md                 # skill 主入口（三段式造物流程）
├── assets/template/         # 数据驱动抽卡站模板（index.html / styles.css / app.js / config.example.js / favicon.svg）
├── scripts/build_site.py    # 照片 + config → 可部署 dist/
└── references/              # 工程规则 / 命名规则 / 稀有度蓝图 / 迁移 prompt / 部署交接
```

## 说明

- 纯前端静态站，无后端；照片默认本地处理，不外传。
- 视觉风格**由你决定**（白底金边只是默认建议之一，也能浪漫紫调 / 暗黑系 / 清新绿）。
- 临时链接可能失效，交付时会附迁移 prompt，方便搬到稳定托管。
- 最后如果想生成在微信里打开的链接，建议交付安装包到work Buddy让它来生成，打开的人就不用翻墙。
  
完整规则见 `SKILL.md`。
